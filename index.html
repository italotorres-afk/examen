Cloud Computing

Es la entrega bajo demanda de recursos de tecnología de la información (potencia de cómputo, almacenamiento de bases de datos, aplicaciones y otros servicios) a través de Internet con un esquema de precios de pago por uso, eliminando la necesidad de mantener centros de datos físicos propios.

SaaS (Software as a Service)

Modelo de distribución donde el proveedor aloja las aplicaciones en la nube y las pone a disposición de los usuarios finales a través de un navegador web. El usuario no gestiona infraestructura ni mantenimiento, solo utiliza el software (ej. Google Workspace, Microsoft 365, Salesforce).

PaaS (Platform as a Service)

Entorno completo de desarrollo e implementación en la nube que proporciona herramientas, sistemas operativos, bases de datos y middleware. Permite a los programadores crear, probar y desplegar aplicaciones sin preocuparse por configurar servidores o redes (ej. Heroku, Google App Engine).

IaaS (Infrastructure as a Service)

Es el nivel más fundamental de servicios en la nube. Ofrece acceso bajo demanda a recursos informáticos básicos virtualizados como servidores, almacenamiento y redes. El cliente tiene control total sobre los sistemas operativos y aplicaciones desplegadas (ej. AWS EC2, Azure Virtual Machines).

Virtualización

Tecnología que permite crear versiones virtuales de recursos físicos (servidores, sistemas operativos, almacenamiento o redes) mediante un software llamado hipervisor. Permite ejecutar múltiples máquinas virtuales aisladas sobre un único hardware físico, optimizando el aprovechamiento de recursos.

img/docker.png

Docker

Plataforma de código abierto que automatiza el despliegue de aplicaciones dentro de contenedores ligeros y portátiles. A diferencia de las máquinas virtuales, los contenedores comparten el núcleo del sistema operativo anfitrión, empaquetando el código y sus dependencias para que funcionen igual en cualquier entorno.
